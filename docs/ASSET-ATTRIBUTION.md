# Asset Attribution

## Visual content

All chamber architecture, FELICIA's layered shells, emissive core, neural filaments,
metallic ribs, memory fragments, particles, reconstruction structures, materials, and recall
traces are project-authored procedurally in TypeScript with Three.js and React Three Fiber.

The interface texture is an inline SVG `feTurbulence` pattern generated by browser code. No
external photographs, textures, environment maps, 3D models, stock footage, or generated
bitmap imagery are included.

## Audio

All audible content is synthesized at runtime with the Web Audio API:

- two quiet oscillators and deterministic filtered noise form the ambient archive;
- fragment cues use scheduled oscillators, envelopes, filters, and stereo panning;
- reconstruction and ending cues use the same procedural graph.

There are no recorded audio files, samples, commercial music, or third-party sound effects.
Audio asset size is therefore zero bytes.

## Fonts

The project bundles and requests no font files. It uses a system stack beginning with
`Avenir Next`, `Segoe UI Variable`, and `Helvetica Neue`, followed by platform sans-serif and
monospace fallbacks. Font rendering and licensing are supplied by the visitor's operating
system. Font asset size is zero bytes.

## Libraries

The experience uses open-source packages including React, Vite, Three.js, React Three Fiber,
Drei, React Three Postprocessing, GSAP, Zustand, Vitest, and Playwright. Their licenses are
preserved in their distributed packages and lockfile metadata. No package artwork or example
assets are redistributed.
